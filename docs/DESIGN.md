# 界面规范

界面用于 TOS 桌面内的文件管理，重点是目录、规则和文件名变化。采用 TOS 的紧凑窗口布局、系统字体和蓝色选中态。

默认窗口为 960×600，标题栏固定 41px，左侧规则区宽 280px，右侧预览使用剩余空间。窄屏按规则、预览顺序排列。TOS 提供实际窗口标题栏及最小化、最大化和关闭按钮。

共享文件夹是目录列表的根层级，路径导航位于文件列表上方。多规则通过有序标签切换，一次显示一条规则的字段。主要动作固定在规则区底部，帮助和语言主题设置位于左下角。

字号使用 12、13、14、16px，控件圆角 4px。桌面表单高 32px，文件行高 34px；窄屏控件及文件行高 44px，虚拟列表使用相同行高。浅深主题共用布局和语义颜色变量。

蓝色表示选择和主要操作，错误同时使用图形与文字。冲突原因显示在新名称下方。应用、窗口内图标和 favicon 共用自写的重命名符号，仅确认对话框使用投影。

保持原生表单、可见键盘焦点、规则标签方向键导航和对话框 Escape 关闭。中英切换覆盖辅助标签、校验原因和任务结果；英文允许换行，文件名与用户输入保留原样。

标题栏和内容区由公共 TosAppShell 提供，分栏与业务状态仍在应用中。通用操作图标采用 Lucide，线宽 1.6px；应用品牌图标继续使用已有的重命名资源。
