# 兼容性

## 支持范围

- TOS 7，x86_64 和 aarch64，浏览器中的 TOS 桌面入口。
- 中文和英文界面，浅色和深色主题；安装元数据覆盖 TOS 的 26 个语言区段，其他语言使用英文说明。
- 内部存储卷上的个人目录及共享目录；应用和文件访问均使用当前 TOS 用户权限。

## TNAS Mobile

当前关闭 TNAS Mobile 入口。已观察到同一手机通过 Safari 登录相同 TOS 地址后应用正常，而 TNAS Mobile 宿主页面无法读取构造 CSRF 请求头所需的 Cookie，网关返回空 403。该对照支持宿主会话兼容性问题的判断，尚无厂商确认的根因或修复版本。

后续恢复入口前，需确认官方会话接入方式，并在真实 TNAS Mobile 上验证启动、目录访问、测试文件改名及撤销。手机浏览器可继续通过 TOS 登录使用。
