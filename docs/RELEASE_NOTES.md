# 0.1.1 Beta

TOS 7 批量重命名工具，支持 x86_64 和 aarch64。

## 更新内容

- 更新应用界面与操作图标，接入 TOS App Kit 0.3.1，统一应用外壳、连接诊断及语言与主题设置。
- 修复应用同名组缺失时的安装问题：安装时创建缺失的系统组，兼容应用用户稍后由 TOS 创建的情况。
- 按 TOS 开发规范调整安装、升级及卸载脚本，修正最低系统版本格式，并统一脚本权限和换行。
- 完善安装升级、数据保留及服务生命周期回归验证。

## 安装与升级

从附件选择对应设备架构的安装包，在 TOS 应用中心手动安装或升级：

| 设备架构 | 安装包 |
| --- | --- |
| x86_64 | `batch-rename_0.1.1_amd64.deb` |
| aarch64 | `batch-rename_0.1.1_arm64.deb` |

升级保留任务记录和应用数据。安装后通过浏览器登录 TOS，从桌面打开“批量重命名”。附件 `SHA256SUMS` 提供安装包的 SHA-256 校验和。

## 使用范围

本版本为 Beta 预发布，支持浏览器中的 TOS 桌面入口；TNAS Mobile 入口暂未开放。批量操作仅处理当前目录，不递归；执行期间请避免其他应用同时修改该目录。
