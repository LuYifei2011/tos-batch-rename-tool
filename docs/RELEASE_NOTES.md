# 0.1.2 Beta

本版更新了 TOS 桌面入口的页面安装方式，并在应用内提供中英双语隐私政策。

## 更新内容

- 在“使用说明”中可离线查看隐私政策，了解任务历史的保留规则，以及查阅、更正和删除记录的方式。
- TOS 从应用的 `webui/` 目录提供页面。升级时先验证新首页，配置成功后清理旧版 `site/` 及其临时目录，保留任务历史和撤销记录。
- 两个架构的 Deb 均由 `dpkg-deb` 构建。包内新增 `docs/BINARY_SOURCE.md`，说明后端源码、构建方式及如何核对 `build-info.json` 中的二进制摘要。
- 最低系统版本字段已更新为平台要求的 `TOS7.0`。

## 安装与升级

在 TOS 7 应用中心手动安装或升级与设备架构对应的包，通过浏览器登录 TOS 后从桌面打开“批量重命名”。

| 设备架构 | 安装包 |
| --- | --- |
| x86_64 | `batch-rename_0.1.2_amd64.deb` |
| aarch64 | `batch-rename_0.1.2_arm64.deb` |

两个安装包的 SHA-256 摘要见附件 `SHA256SUMS`。

本版支持浏览器中的 TOS 桌面入口，TNAS Mobile 入口暂未开放。批量操作仅处理当前目录。执行期间请避免其他应用同时修改该目录。
